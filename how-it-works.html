How it works

The server is yours. The app is the same everywhere.

Each Aulora server hosts one workspace. People open it in a browser or add its URL to the desktop or mobile app. One install of the app can hold every server they belong to.

One app. A server for each group.

Work, a club, and a side project each run their own server. Pick one in the rail. Signing in on one does not sign you in on the others.

Everything a team talks through, no add-ons.

Channels, calls, files, and the admin tools, all in the same server. Nothing here is sold separately.

Talk

  • Channels and categoriesPublic, private, and announcement channels, sorted into categories.
  • ThreadsReplies stay attached, and a threads inbox brings you back to them.
  • Direct and group messagesPresence shows who's online, idle, or on do not disturb.
  • Mentions and reactions@people and #channels, with per-channel mute and notification settings.
  • FilesDrag in files and images. The upload limit is yours to set.
  • SearchJump to any channel, person, or message with ⌘K.

Call

  • Voice channelsDrop in and out like walking into a room.
  • Video callsWebRTC on web, desktop, and mobile, starting from any conversation.
  • Screen sharingWhere the platform supports it.
  • Incoming callsCall alerts on web, desktop, and mobile.
  • Your own TURNAdd your own ICE servers for networks that block direct connections.

Run

  • Roles and overridesWorkspace roles, plus allow and deny overrides on each channel.
  • Invites and signup policyOpen signup or invite only, with email, OAuth, or OIDC sign-in.
  • ModerationTimeouts, bans, and an audit log of admin actions.
  • Nightly backupsAn optional backup runner, plus a documented restore drill.
  • Release updatesA host updater with owner controls in settings, or redeploy a tag on Coolify.
