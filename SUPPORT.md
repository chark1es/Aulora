# Getting help

Start with the [setup guide](apps/docs/content/getting-started.md) and [troubleshooting](apps/docs/content/troubleshooting.md). Operators should also check the [deployment guide](infra/docker/README.md).

For bugs and feature requests, use [GitHub Issues](https://github.com/chark1es/Aulora/issues). Include the Aulora version or commit, platform, steps to reproduce, expected result, actual result, and relevant redacted logs. State whether the issue affects the browser, desktop app, mobile app, or server.

For commercial licensing and other private project inquiries, email [cnguyen@spwnd.dev](mailto:cnguyen@spwnd.dev). There is no guaranteed support response time unless your commercial agreement provides one.

For vulnerabilities, use [SECURITY.md](SECURITY.md). Never attach `.env`, private signing files, encryption keys, or real chat exports to a public issue.
