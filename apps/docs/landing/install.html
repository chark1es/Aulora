Install

Get the app. Or run the server.

Aulora is two pieces. The client is the app you open to join a workspace. The workspace is the server that holds the messages, files, and accounts. Most people only install the client. One person per team runs the server.

Get the app

The button follows this computer. iOS and Android are in beta.

Step one · the client

Join a workspace.

The client connects to a server someone already runs. You need that server's web URL, and an invitation if signup is closed. Nothing here needs Docker.

Step two · the workspace

Run the server.

Do this once, on a machine you control. You need Git and Docker with Compose v2.24 or newer. Bun, Node.js, and Rust are not required to run a workspace.

  1. Run the installer

    It asks for an owner email and password, generates secrets, builds the stack, and creates the workspace. On Windows, run pwsh ./install.ps1. That script installs the server, not the Windows app.

  2. Back up .env somewhere else

    It holds the encryption key. A database backup is useless without it.

  3. Give it a real address

    Set up DNS, HTTPS, and origins with the self-hosting guide, or deploy on Coolify.

  4. Invite the team

    They install a client or open the URL. You create channels, roles, and invites from workspace settings.

{{icon:pin}}Before you run a server

Know who can read what.

Self-hosting only helps if the trust model is clear. Here it is in plain terms.

{{icon:check}}What Aulora does

  • Encrypts message content and uploads at rest with a key you generate and keep.
  • Keeps chat data in Postgres and object storage on infrastructure you run.
  • Sends mobile push as generic wakeups through your relay, not message bodies.
  • Reports billing as monthly counts only: no names, emails, or messages.

{{icon:x}}What it doesn't do

  • It isn't end-to-end encrypted. The server decrypts content for signed-in users, so the operator has to be trusted.
  • It isn't a hosted service. You run the machine, the backups, and the updates.
  • It can't recover data without the key. Lose AULORA_ENCRYPTION_KEY and your messages are gone.
  • Windows client installers are unsigned for now, so Windows may warn you the first time.
