How it works

The server is yours. The app is the same everywhere.

Each Aulora server hosts one workspace. People open it in a browser or add its URL to the desktop or mobile app. One install of the app can hold every server they belong to.

One app. A server for each group.

Work, a club, and a side project each run their own server. Pick one in the rail. Signing in on one does not sign you in on the others.

Everything a team talks through, no add-ons.

Channels, calls, files, and the admin tools, all in the same server. Nothing here is sold separately.

Talk

  • {{icon:hash}}Channels and categoriesPublic, private, and announcement channels, sorted into categories.
  • {{icon:thread}}ThreadsReplies stay attached, and a threads inbox brings you back to them.
  • {{icon:message}}Direct and group messagesPresence shows who's online, idle, or on do not disturb.
  • {{icon:at}}Mentions and reactions@people and #channels, with per-channel mute and notification settings.
  • {{icon:paperclip}}FilesDrag in files and images. The upload limit is yours to set.
  • {{icon:search}}SearchJump to any channel, person, or message with ⌘K.

Call

  • {{icon:volume}}Voice channelsDrop in and out like walking into a room.
  • {{icon:video}}Video callsWebRTC on web, desktop, and mobile, starting from any conversation.
  • {{icon:monitor}}Screen sharingWhere the platform supports it.
  • {{icon:phone-incoming}}Incoming callsCall alerts on web, desktop, and mobile.
  • {{icon:signal}}Your own TURNAdd your own ICE servers for networks that block direct connections.

Run

  • {{icon:shield}}Roles and overridesWorkspace roles, plus allow and deny overrides on each channel.
  • {{icon:user-plus}}Invites and signup policyOpen signup or invite only, with email, OAuth, or OIDC sign-in.
  • {{icon:ban}}ModerationTimeouts, bans, and an audit log of admin actions.
  • {{icon:download}}Nightly backupsAn optional backup runner, plus a documented restore drill.
  • {{icon:settings}}Release updatesA host updater with owner controls in settings, or redeploy a tag on Coolify.
